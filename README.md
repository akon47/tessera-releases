## 한국어

**Tessera**는 브라우저에서 즐기는 3D 복셀 생존 멀티플레이 게임입니다. 월드에 떨어져 블록을 캐고, 제작하고, 짓고, 밤의 몹을 버티며 같은 오픈 월드에서 다른 플레이어들과 함께 살아남으세요.

이 레포는 **Windows 데스크톱 앱 설치 파일**을 배포합니다. 데스크톱 앱은 브라우저 크롬 없이 전체 화면으로 도는 네이티브 창이며, **같은 서버에 접속**하므로 계정·멀티플레이는 웹 버전과 완전히 동일합니다.

### 설치
1. [최신 릴리스](https://github.com/akon47/tessera-releases/releases/latest)에서 `Tessera-Setup-<버전>.exe` 다운로드
2. 실행 → 설치 위치 선택 → 설치
3. ⚠️ 서명되지 않은 빌드라 처음 실행 시 Windows SmartScreen이 경고합니다 → **추가 정보 → 실행**

### 자동 업데이트
- **게임 콘텐츠**(렌더링·UI·게임플레이)는 항상 라이브 서버에서 로드되어 **자동으로 최신**입니다.
- **앱 자체**도 실행할 때 새 버전을 확인해 백그라운드로 받아 종료 시 설치합니다. 따로 받을 필요가 없습니다.

### 조작

### 시스템 요구사항
- Windows 10/11 (64-bit)
- 인터넷 연결 (멀티플레이 서버 접속)

## English

**Tessera** is a browser-based 3D multiplayer voxel survival game. Spawn into a shared open world — mine, craft, build, and survive the night together.

This repo distributes the **Windows desktop installer**. The desktop app is a chrome-less, fullscreen native window that connects to the **same server**, so accounts and multiplayer are identical to the web version.

### Install
1. Grab `Tessera-Setup-<version>.exe` from the [latest release](https://github.com/akon47/tessera-releases/releases/latest).
2. Run it → choose an install folder → install.
3. ⚠️ The build is unsigned, so Windows SmartScreen warns on first launch → **More info → Run anyway**.

### Auto-update
- **Game content** (rendering, UI, gameplay) always loads live from the server, so it's **always current**.
- **The app itself** checks for a newer version on launch, downloads it in the background, and installs on quit — no manual downloads.

### Controls
Click to lock the mouse · WASD move · Space jump (swim up) · Shift sprint/descend · L-click mine · R-click place · 1–9 / wheel hotbar · E inventory & crafting · Enter chat · ESC menu · F11 fullscreen

### Requirements
- Windows 10/11 (64-bit)
- Internet connection (multiplayer server)
